### 🔬 Research Focus: Efficient Legal AI

Legal clients require **data privacy** and **low latency**. I research methods to run powerful AI locally, without sending sensitive data to the cloud.

| Area | Topics I'm Exploring |
| :--- | :--- |
| **SLMs in Legal** | Benchmarking **Phi-3**, **Mistral**, and **Gemma** for contract summarization performance vs. GPT-4. |
| **Quantization** | Implementing **AWQ** and **GGUF** formats to deploy legal agents on consumer hardware (MacBook/Edge devices). |
| **Fine-Tuning** | Using **QLoRA** (Quantized Low-Rank Adapters) to teach small models legal jargon with minimal compute. |

### 📂 Featured Projects

#### 1. ⚖️ LegalTech Agentic Automation
> *A multi-model agentic system designed to autonomous routine legal workflows.*
* **Objective:** Automate legal document review and task execution using autonomous agents.
* **Architecture:** Orchestrated via **LangChain** with a hybrid model approach—using **OpenAI GPT-4** for reasoning and **Google Gemini** for large-context document processing.
* **Key Features:**
    * Implemented agentic tools for drafting, summarization, and precedent retrieval.
    * Reduced manual document processing time by leveraging high-context windows.

#### 2. 🛡️ Qwen-Security-FineTune
> *Fine-tuned LLM for Cybersecurity Incident Analysis.*
* **Objective:** Create a specialized model capable of analyzing system logs and explaining security failures or vulnerabilities in plain English.
* **Methodology:** Fine-tuned the **Qwen** base model on a curated dataset of CVEs (Common Vulnerabilities and Exposures) and security incident logs.
* **Tech Stack:** Python, PEFT/LoRA (Low-Rank Adaptation), Hugging Face Transformers.
